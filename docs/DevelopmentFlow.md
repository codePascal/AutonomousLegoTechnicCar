# Development flow

## Create remote development environment in VS Code

1. Install the `Remote - SSH extension`
2. Add the Raspberry Pi as an SSH host: `Remote-SSH: Add New SSH Host...`
3. Enter the SSH command used to connect to the Raspberry Pi
4. Connect to the Raspberry Pi: `Remote-SSH: Connect to Host...`
5. Select previously added host
6. Select `Linux` as operating system if asked
7. Open the closed project repository: `File → Open Folder`
